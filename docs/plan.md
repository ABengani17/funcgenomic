# Twelve-Week Plan

## Weeks 1-2

- Fix the initial crop set.
- Standardize the schema.
- Decide what counts as strong enough evidence to enter the table.

## Weeks 3-5

- Curate the first tranche of host targets.
- Add citation-level provenance for each row.
- Separate direct evidence from inference.

## Weeks 6-8

- Stress test the ranking rubric.
- Compare obvious high-value targets against awkward but realistic counterexamples with worse deployability or worse fitness tradeoffs.
- Refine the weighting only where the reasons are clear.

## Weeks 9-10

- Write a short memo on the most plausible targets for follow-up.
- Identify where the table is still too sparse to support strong claims.

## Weeks 11-12

- Package the dataset and memo cleanly.
- Turn the top few candidates into validation sketches with assay ideas, partner types, and cost assumptions.
