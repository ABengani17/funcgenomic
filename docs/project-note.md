# Project Note

## Working claim

For some crop systems, the right unit of analysis is not the pathogen itself but the host process it repeatedly depends on. If that is true, then there is room for a more systematic way to compare targets across pathogens and crops instead of handling each pathosystem in isolation.

## What this project is trying to do

This project is a small prototype for that comparison problem.

The deliverable is not a model in the grand sense. It is a compact atlas plus a ranking rule:

- collect examples of host dependency factors or susceptibility pathways;
- annotate how strong the evidence is;
- note whether the same pathway appears across multiple pathogen classes;
- keep track of intervention modality and likely agronomic downside;
- rank candidates in a way that can be inspected and argued with.

## Why this seems worth doing

There are already credible examples that support the basic framing:

- rice bacterial blight resistance via editing pathogen-targeted SWEET promoter elements;
- broad disease resistance from edited host pathways such as RBL1, though sometimes with nontrivial fitness tradeoffs;
- structurally convergent effector biology in phytopathogens, suggesting that sequence diversity does not imply infinite functional diversity.

At the same time, agricultural biosecurity is still mostly organized around outbreaks, surveillance, and individual pathogens. That leaves a gap for a quieter kind of infrastructure: comparative target selection.

## What would count as success in twelve weeks

Reasonable scope for a first serious pass:

1. Build a literature-backed table covering a few crop-pathogen systems.
2. Make the ranking rubric explicit enough that domain experts can disagree with it productively.
3. Produce a short list of candidate targets that look broad enough to matter and safe enough to be interesting.
4. Write down what a real validation handoff would look like.

## What this project is not

- not a full platform
- not a replacement for wet-lab work
- not a claim that broad-spectrum crop defense is easy

It is a way of making a messy problem more legible.
