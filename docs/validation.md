# Validation Notes

The main constraint is not finding plausible targets. It is finding targets that survive contact with agronomy.

For that reason, each candidate should eventually be judged on at least four axes:

1. Does perturbing the target reliably reduce disease burden?
2. Does the effect generalize across strains or pathogen classes?
3. Is there an acceptable yield or growth penalty?
4. Is there a realistic route to deployment in the crop system in question?

That suggests a modest validation package for each promising target:

- infection assay in an established model system
- measurement of resistance effect size
- basic growth and fitness readout
- some attempt to separate “interesting mechanism” from “field-plausible intervention”

If the project moved beyond the prototype stage, the first useful collaborators would be plant pathology labs and crop genetics groups that already run these assays routinely.
